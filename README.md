# Karmic Healing Flutter

Flutter версія додатку Karmic Healing - додаток для духовного лікування та балансування енергії.

## Функціональність

### 🏠 Головний екран
- Навігація по основним розділам додатку
- Красивий градієнтний фон
- Адаптивна сітка кнопок

### 🎯 Onboarding
- Вступний екран для нових користувачів
- Пошагове знайомство з функціональністю
- Можливість пропустити

### ⚡ Балансування енергії
- **Початковий процес** - для нових користувачів
- **Есенціальне Я** - підключення до свого справжнього Я
- **Божественне Я** - підключення до вищого аспекту
- Детальні інструкції для кожної практики
- Прогрес-індикатор

### 📝 Запити (Requests)
- Створення та управління запитами на лікування
- Пріоритети (низький, середній, високий)
- Дати виконання
- Пошук та фільтрація
- Статус виконання

### 🔔 Нагадування (Reminders)
- Створення нагадувань для практик
- Прапорці для важливих нагадувань
- Дати та час
- Пошук та управління

### ⚙️ Налаштування
- Темна/світла/системна тема
- Мови (англійська, українська)
- Сповіщення
- Експорт/імпорт даних
- Очищення даних

## Технології

- **Flutter** - крос-платформна розробка
- **GetX** - управління станом та навігація
- **SharedPreferences** - збереження налаштувань
- **SQLite** - локальна база даних
- **Material Design** - дизайн-система

## Встановлення

1. Клонуйте репозиторій:
```bash
git clone <repository-url>
cd karmic_healing_flutter
```

2. Встановіть залежності:
```bash
flutter pub get
```

3. Запустіть додаток:
```bash
flutter run
```

## Особливості дизайну

- **Градієнтний фон** - створює атмосферу спокою
- **Золоте співвідношення** - для пропорцій кнопок
- **Консистентні відступи** - використання DesignConstants
- **Кольорова схема** - дружні кольори для духовного додатку
- **Адаптивність** - працює на різних розмірах екранів
